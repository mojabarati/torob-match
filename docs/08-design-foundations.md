# Foundations طراحی

منبع دادهٔ قابل‌ماشین‌خواندن این سند در [`data/design-tokens.json`](../data/design-tokens.json) قرار دارد. همان نام‌ها باید در متغیرهای Figma و CSS پیاده‌سازی React استفاده شوند.

## جهت بصری

- رابط روشن و RTL؛
- ساختار جست‌وجو و مقایسه با الهام از ترب، بدون تقلید مستقیم؛
- قرمز به‌عنوان رنگ عمل اصلی و هویت؛
- سطح‌های سفید روی پس‌زمینهٔ خنثی؛
- سبز برای تناسب فعلی، کهربایی برای انعطاف و بنفش برای گزینهٔ کششی؛
- نمایش واضح عدم‌قطعیت بدون تبدیل آن به خطا.

## تایپوگرافی

فونت اصلی Vazirmatn است. وزن‌های Regular، SemiBold و Bold برای متن، label و عنوان استفاده می‌شوند. متن‌های انگلیسی داخل رابط نیز با همین خانواده نمایش داده می‌شوند تا خط مبنا و ارتفاع سطر در متن ترکیبی فارسی–انگلیسی پایدار بماند.

## قرارداد پیاده‌سازی

- نام متغیر Figma: `color/background/page`
- نام CSS: `var(--color-background-page)`
- نام داده: `semantic.color.background-page`

همین تبدیل برای فاصله، شعاع و اندازهٔ کنترل‌ها اعمال می‌شود. مقدارهای Primitive مستقیماً در کامپوننت مصرف نمی‌شوند؛ کامپوننت‌ها فقط به توکن‌های Semantic متصل می‌شوند.

## حداقل‌های دسترس‌پذیری

- متن معمولی نسبت کنتراست حداقل ۴٫۵:۱ دارد؛
- متن درشت نسبت حداقل ۳:۱ دارد؛
- focus ring مستقل از رنگ وضعیت دیده می‌شود؛
- کنترل‌های لمسی حداقل ۴۴ پیکسل ارتفاع دارند؛
- وضعیت‌های مطلوب، منعطف و کششی علاوه بر رنگ، برچسب متنی دارند.
