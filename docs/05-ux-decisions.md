# تصمیم‌های تجربه‌ی کاربری

وضعیت: آماده‌ی طراحی تجربهٔ صفحهٔ نتایج بر پایهٔ رتبه‌بندی پویا

در مرحلهٔ بعد باید نحوهٔ نمایش سه پیشنهاد برجسته، سایر گزینه‌ها، دلیل رتبه، کمبودها، هشدارهای داده، تغییر لازم برای دسترسی و مقایسهٔ کنارهمی طراحی شود. این سند عمداً هنوز وارد تصمیم‌های چیدمان و تعامل نشده است.
