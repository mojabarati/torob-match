# دوره‌یاب (DorehYab)

دوره‌یاب نمونه‌ی یک محصول جست‌وجو و مقایسه برای دوره‌ها و بوت‌کمپ‌های فارسی حوزه‌های هوش مصنوعی، داده و برنامه‌نویسی است. محصول نیاز کاربر را از زبان طبیعی به معیارهای قابل‌ویرایش تبدیل می‌کند، همه‌ی گزینه‌های معتبر را نگه می‌دارد و نشان می‌دهد هر دوره با شرایط فعلی یا با چه میزان انعطاف در بودجه، زمان و مهارت قابل انتخاب است.

## وضعیت پروژه

مرحله‌ی فعلی: **داده و رتبه‌بندی پویا تکمیل شده؛ آماده‌ی طراحی تجربه‌ی صفحه‌ی نتایج**

سناریوی مرجع، سارا، توسعه‌دهنده‌ی بک‌اندی است که می‌خواهد RAG را به محصول شرکت اضافه کند. مقدار شروع او ۵ میلیون تومان، ۱۲ هفته و ۶ ساعت در هفته است؛ این مقادیر نقطه‌ی شروع‌اند و سقف ثابت محصول نیستند.

## ساختار ریپازیتوری

```text
doreh-yab/
├── README.md
├── docs/                       # تحقیق، مسئله، مشخصات و تصمیم‌ها
├── data/
│   ├── courses.json            # هشت دوره‌ی واقعی و قابل ردیابی
│   ├── course.schema.json
│   ├── sample-query.json
│   ├── search-query.schema.json
│   ├── sample-ranking.json
│   └── sample-scenarios.json
├── app/ranking.py              # رتبه‌بندی توضیح‌پذیر
└── tests/test_ranking.py
```

## اصول پروژه

- مسئله‌ی کاربر مقدم بر قابلیت‌های نمایشی است.
- AI نیاز آزاد کاربر را ساختار می‌دهد؛ محاسبه و رتبه‌بندی قابل‌آزمون و قطعی‌اند.
- هیچ دوره‌ی معتبر صرفاً به‌خاطر ناسازگاری با مقدار شروع کاربر پنهان نمی‌شود.
- دلیل امتیاز، کمبود، داده‌ی نامشخص و تغییر لازم برای هر گزینه نمایش‌پذیر است.
- داده‌ی نمونه منشأ، تاریخ مشاهده و سطح اطمینان دارد.

## تصمیم فعلی

بازار انتخاب‌شده، دوره‌ها و بوت‌کمپ‌های فارسی یا فارسی‌دسترس برای رسیدن به یک هدف فنی مشخص است. [تحقیق بازار](docs/01-market-research.md)، [مسئله‌ی کاربر](docs/02-user-problem.md)، [مشخصات محصول](docs/03-product-spec.md) و [داده و رتبه‌بندی](docs/04-data-and-ranking.md) مسیر تصمیم را ثبت می‌کنند.

کنترل بودجه از صفر تا ۳۰ میلیون تومان است. در سناریوی سارا، ۵ میلیون مقدار مطلوب و ۱۰ میلیون مرز انعطاف اولیه است؛ کاربر می‌تواند هر دو را تغییر دهد. زمان و سطح مهارت نیز به همین شکل پویا هستند.

برای اجرای رتبه‌بندی:

```powershell
python -m app.ranking --courses data/courses.json --query data/sample-query.json
```

برای اجرای آزمون‌ها:

```powershell
python -m unittest discover -s tests -v
```
